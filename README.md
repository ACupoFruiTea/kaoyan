## 当前阶段：极简总方案（2026-10-20 起，只管这 5 条）
1. **起床**：每天同一时间起床，出门见光；不困不上床。
2. **学习**：上午先做一块最难的（做题、合上书回忆），这块是底线；其余时间正常学，晚饭后只轻复习或不学；头 1–2 周每天总量约 7 小时。
3. **娱乐**：每天留一段自选娱乐，在"目标入睡时间减 2 小时"前结束；不打排位，输了就停；结束后不打游戏、不刷短视频。
4. **手机**：学习时不放桌上，睡觉时不放床边。
5. **睡不着**：躺很久仍很清醒就起来，暗光下做件无聊的事（不碰手机），困了再回床。

过程信号：连续两三晚都很难受、要硬忍，说明量太猛，就主动减量或延长娱乐时段，不要继续忍。其余方案文件中的细则（KSS、A/B/C 分层计算、记录表等）暂时不用执行，留作参考。
